Para empezar

Revisá los costos de compra, después registrá una venta de prueba solo cuando estés listo. La app comparte el stock con la tienda online. Registrá una venta solo cuando esté confirmada.

Importante: antes de vender, completá el costo de compra de cada producto. La ganancia se calcula usando ese costo guardado.
